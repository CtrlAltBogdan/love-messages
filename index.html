Love Messages

Про проект

Це веб-додаток для створення та обміну анімованими листівками

Основні можливості:

  • Створення персоналізованих листівок
  • Анімовані персонажі (Stanislava та Yana)
  • Шифрування даних в URL
  • Адаптивний дизайн
  • Компресія даних для коротких посилань

Технічний стек:

Frontend: Vanilla JavaScript, CSS3, HTML5
Шифрування: LZ-String (компресія)
Анімації: CSS Keyframes

Як це працює:

1. Створення листівки


const cardData = {
    n: "Настя",              // Ім'я отримувача
    text: "Привіт! ❤️",      // Текст повідомлення
    theme: "stanislava",     // Тема (персонаж)
    sender: "Анонім"         // Відправник
};

// Конвертуємо об'єкт в JSON
const jsonData = JSON.stringify(cardData);

// Стискаємо дані
const compressed = LZString.compressToEncodedURIComponent(jsonData);

// Формуємо безпечне посилання
const url = `love/index.html?data=${compressed}`;

2. Відкриття листівки


// Отримуємо дані з URL
const params = new URLSearchParams(window.location.search);
const compressed = params.get("data");

// Розпаковуємо дані
const jsonData = LZString.decompressFromEncodedURIComponent(compressed);
const cardData = JSON.parse(jsonData);

// Рендеримо листівку
renderCard({
    name: cardData.n,
    message: cardData.text,
    theme: cardData.theme,
    sender: cardData.sender
});
